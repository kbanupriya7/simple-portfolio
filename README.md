# My Personal Portfolio

## About the Project

This is my first simple personal portfolio website, created using HTML and CSS as part of my Full Stack Web Development learning journey.

The website introduces me, showcases my interests and projects, and includes a separate contact page with a contact form.

## Features

- Personal introduction and About Me section
- Interests section
- Projects showcase
- Contact page with a form
- GitHub and LinkedIn profile links
- Custom styling using CSS and Google Fonts

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Pages

- **Home (`index.html`):** Personal introduction, interests, projects, and social media links.
- **Contact (`contact.html`):** Contact form with name, email, contact number, and message fields.

## What I Learned

Through this project, I practised structuring web pages with HTML, styling elements with CSS, creating links between pages, and designing a basic contact form.

## Future Improvements

- Make the website responsive for mobile devices.
- Connect the contact form to a backend to receive messages.
- Add live links to my projects.
